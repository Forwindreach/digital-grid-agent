## 三、跨部门联动规则

| 场景 | 联动部门 |
|------|----------|
| 物业纠纷涉及违建 | 区住建局 + 区城管局 |
| 噪音涉及商业经营 | 区生态环境局 + 公安机关 |
| 公共安全隐患 | 区应急管理局 + 属地街道 + 相关职能部门 |
| 职责不明 | 智慧中心指定兜底单位 |
