# 福州市环境卫生管理法规 — 关键条款

> 涵盖《福州市生活垃圾分类管理条例》（2020年施行）与《福州市市容和环境卫生管理办法》。

---

## 一、垃圾分类标准

| 类别 | 内容 |
|------|------|
| 可回收物 | 废纸、塑料、金属、纺织物、电子电器、玻璃、木料 |
| 易腐垃圾 | 餐饮垃圾、厨余垃圾 |
| 有害垃圾 | 废弃电池、荧光灯管、药品、油漆、农药 |
| 大件垃圾 | 重量>5kg 或 体积>0.2m³ 或 长度>1m 的废旧家具家电 |
| 其他垃圾 | 以上四类之外的生活废弃物 |

---

## 二、管理责任人

实行物业管理的区域 → **物业服务企业**为责任人；未实行物业管理的 → 经营管理单位为责任人。

---

## 三、常见违规与处罚

| 违规行为 | 处罚 |
|----------|------|
| 个人未按规定分类投放垃圾 | 责令改正，逾期不改罚款 **50-200元** |
| 单位未按规定分类投放 | 罚款 **1万-5万元** |
| 管理责任人（单位）未履行职责 | 罚款 **1000-5000元** |
| 管理责任人（个人）未履行职责 | 罚款 **50-200元** |
| 混合收集运输已分类垃圾 | 罚款 **1万-3万元** |
| 沿途丢弃、遗撒生活垃圾 | 罚款 **2万-5万元** |
| 处置企业未按要求处置 | 罚款 **3万-10万元** |
| 不在指定地点停放车辆 | 罚款 **10元** |
| 擅自占道经营 | 罚款 **200元** |
| 未履行"门前三包"责任 | 罚款 **200元** |

---

## 四、监管部门

**各区城市管理局（综合执法局）**负责执法，2024年全年持续常态化处罚。
