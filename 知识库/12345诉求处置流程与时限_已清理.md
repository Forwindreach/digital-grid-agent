# 福州市12345便民服务平台 — 诉求处置流程与时限

> 适用于福州全市，网格员事件上报后接入12345体系的处置规范。

---

## 一、诉求分类

| 类别 | 说明 |
|------|------|
| **咨询类** | 对政策规定、办事流程等政务信息的咨询 |
| **投诉类**（含举报类） | 对行政管理、社会管理、公共服务等工作的投诉 |
| **建议类**（含感谢类） | 对行政管理、社会管理等方面的意见和建议 |
| **求助类** | 对行政职权范围内的管理、服务等方面的求助 |

---

## 二、办理时限（核心数据，对应 Demo 的"预计时限"）

| 诉求类型 | 市级标准 | 鼓楼区街道标准 |
|----------|----------|---------------|
| **紧急事项** | 当天答复 | **12小时内** |
| **咨询类** | 2个工作日 | **1个工作日（24小时）** |
| **求助类** | 3个工作日 | **2个工作日** |
| **建议类** | 5个工作日 | **3个工作日** |
| **投诉类/举报类** | 10个工作日 | **7个工作日** |

> 延期需提前半个工作日申请，延长时限不超过原办理时限。

---

## 三、闭环处置流程

```
【事件上报】
    │ 网格员 / 居民通过12345 / e福州 / 微信小程序
    ▼
【受理签收】
    │ 经办10-30分钟内确定签收
    ▼
【分派流转】
    │ 派发业务科室 → 自处或转发社区
    │ 不属于本科室业务的 → 30分钟内提出转办
    │ 涉及多科室的 → 指定一个科室牵头
    │ 职责不明的 → 智慧中心指定兜底单位
    ▼
【办理反馈】
    │ 逐点作答，正面回应
    │ 社区办理的需经社区书记签字
    └── 确实无法解决的 → 联系诉求人耐心解释

【办结归档】
```

---

## 四、一线处置机制（鼓楼区特色）

鼓楼区依托**"鼓楼智脑"平台**，为街道（社区）连通职能部门：

- 街镇/社区可实时**"呼叫"**相关部门
- 部门须在规定时限内响应到场
- 平台全留痕处理
- 推诿扯皮的推送**纪检监察机关跟进监督**

---

## 五、不满意与申诉

- 不满意件可提请重新办理
- 经核实存在不作为的 → **街道效能办介入督办**
- 仍不满意的 → **街道纪工委谈话、问责**
