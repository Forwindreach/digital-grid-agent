# 福州市环境噪声污染防治若干规定（2012年修正版）

> 2008年5月1日起施行，2012年修正。适用于福州市全部行政区域。

---

## 监管部门职责（第三条）

| 部门 | 职责 |
|------|------|
| 环境保护行政主管部门 | 统一监督管理 |
| 公安机关 | 机动车辆噪声及相关社会生活噪声 |
| 城市管理执法部门 | 建筑施工噪声（城管相对集中处罚权区域） |
| 交通、海事部门 | 机动船舶噪声 |

---

## 禁止行为清单（第十七条，核心条款）

在城市噪声敏感建筑物集中区域内，**禁止**：

1. 商业经营场所外安装音响器材播放音乐广告、沿街叫卖
2. **午间（12:00-14:30）和夜间（22:00-次日6:00）**从事装修、制作家具、货物装卸等扰民活动
3. 午夜间体育锻炼、播放音乐、吹奏乐器、歌咏等活动
4. 饲养动物产生噪声干扰他人休息
5. 其他产生环境噪声污染的行为

---

## 建筑施工噪声（第十三条）

噪声敏感建筑物集中区域内，**禁止午、夜间进行产生噪声污染的施工作业**。因工艺要求确需施工的，须报环保部门批准并公告。

---

## 住宅小区噪声（第九条）

- 住宅小区内不得违反规划新建产生噪声污染的饮食、娱乐项目
- 已建成项目噪声须符合排放标准，不符合的由环保部门责令限期治理
- 营业性饮食和娱乐场所噪声扰民经调解无效的，可**限制其夜间经营时间、范围**

---

## 投诉与报告机制

- **第四条**：物业服务企业对本区域内违反噪声污染防治规定的行为，应予以**劝阻**；劝阻无效的，及时向**环保部门**报告
- **第五条**：环保部门应设置并公开举报投诉电话，统一受理后按职责分工交相关部门办理

---

## 处罚标准（摘录）

| 违法行为 | 处罚 |
|----------|------|
| 制造噪声干扰他人正常生活（违反广场舞、装修时间等） | 公安批评教育或警告；不改正的处 **200-500元** |
| 文化娱乐场所边界噪声超标 | 责令改正，并处 **1万-5万元** |
| 住宅小区内违法经营噪声污染项目 | 责令改正，处 **5000-2万元** |
| 限制区域时间内产生噪声污染拒不改正 | 处 **1000-5000元**，可封存暂扣物品 |
| 逾期未完成限期治理（单位） | 处 **1万-10万元** |
| 逾期未完成限期治理（个体户） | 处 **5000-2万元** |

---

## 时间定义（第二十五条）

| 时段 | 时间范围 |
|------|----------|
| **午间** | 12:00 — 14:30 |
| **夜间** | 22:00 — 次日 6:00 |
| **噪声敏感建筑物** | 医院、学校、办公楼、写字楼、住宅 |
| **噪声敏感建筑物集中区域** | 医疗区、文教区、科研区、居民住宅为主的区域 |

---

## 2024年执法动态

福州市常态化推进**"静夜守护"**专项行动。台江区2024年共受理噪声投诉**379件**，下达限期改正7份，立案查处5家，联合执法16次。投诉渠道：**12345**（主力）、**12369**（环保热线）。
