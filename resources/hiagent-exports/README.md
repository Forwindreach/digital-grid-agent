# HiAgent 导出包

这里保存比赛版本的 HiAgent 应用、子智能体和知识库导出包，用于复现多 Agent 编排结构。

| 文件 | 内容 |
| --- | --- |
| `digital-grid-agent-v1.0.0.zip` | 数字网格员主应用 |
| `intent-classifier-agent.zip` | 意图分类助手 |
| `policy-qa-agent.zip` | 政策解答专家 |
| `ticket-processing-agent.zip` | 工单处理 Agent |
| `gulou-policy-kb.tar.gz` | 鼓楼区政务咨询知识库导入包 |

导入前请阅读 [`docs/HiAgent配置指南.md`](../../docs/HiAgent配置指南.md)。访问凭证不会包含在导出包中。
