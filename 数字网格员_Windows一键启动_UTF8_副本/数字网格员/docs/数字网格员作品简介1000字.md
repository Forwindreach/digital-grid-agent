# 数字网格员：AI Agent 驱动的社区治理自动化

数字网格员是一套面向社区网格治理场景的 AI Agent 系统，基于火山引擎 HiAgent 平台构建，以微信小程序作为居民服务入口，以数字网格员网页端作为基层处置工作台。系统将“居民诉求到人工分拣到人工处置到人工回访”的传统流程，改造为“多端接入、智能识别、信息补齐、标准化工单、网格自动分派、网格员处置、居民反馈、人工归档”的自动化闭环。

社区治理长期面临渠道分散、信息不全、派单不准、回复口径不一致等问题。居民通过微信群、电话、小程序反映诉求，网格员需要重复登记和分拣；工单常缺少详细住址、持续时长、发生频率等关键信息，责任部门难以快速处置。数字网格员针对这些痛点，让 HiAgent 承担高频、标准化工作，把网格员从重复劳动中解放出来。

居民在小程序中先登记姓名、手机号、社区、网格和楼栋房号，再通过自然语言描述投诉或政策咨询。HiAgent 会主动追问事发地址、发生时间、持续时长、发生频率、是否已反映等信息，并在确认后生成结构化工单。工单同时保留居民登记住址与事发地址，完整记录问题描述、责任部门、优先级、响应时限和处置状态，避免聊天记录直接充当工单。

数字网格员网页端支持标准 Excel 表格批量导入居民和诉求，适合微信群回收登记表后统一录入；同时保留灵活新增登记入口，年龄较大的居民可由网格员代为登记，降低数字鸿沟。系统采用后端强制权限隔离，区分系统管理员、街道管理员、社区负责人和网格员。工单创建后按社区和网格自动匹配责任网格员，网格员只能查看派给自己的工单，社区负责人可查看本社区工单，管理员可查看全部工单。支持自动派单、手动改派、实时刷新和处置归档，确保“人在格中走，事在格中办”。

数字网格员遵循“Agent 自动执行、人工最终确认”的人机协同原则。Agent 负责意图识别、政策知识库检索、工单起草和居民回复；网格员负责工单确认、处置、改派与归档。系统不替代基层工作者，而是通过 AI 补齐信息、规范流程、降低差错，让网格员把精力集中在真正需要人工判断的事务上。项目提供 Windows、macOS 和 Linux 一键部署脚本，并接入 HiAgent 真实流式接口，具备面向街道和社区复制的工程化基础，为基层治理数字化转型提供可落地的实践方案。
