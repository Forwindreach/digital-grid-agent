# 数字网格员系统使用说明书

本说明书面向评审人员、社区网格员和小程序测试人员，说明数字网格员系统的 Windows 一键启动方法、数字网格员网页端操作流程、微信小程序使用方式，以及 Excel 批量导入、适老化灵活登记和 HiAgent 配置方式。

## 一、说明书用途

本说明书用于指导测试人员在不修改源码的情况下运行和体验数字网格员系统。测试人员无需准备 HiAgent API Key，也可以直接使用本地模拟模式完成居民登记、对话、工单生成、网格分派和权限验证。

如果测试人员需要验证真实 HiAgent 对话，只需在首次启动时填写自己的 HiAgent 接口地址、应用 ID、工作流 ID 和 API Key。API Key 只保存在本机后端运行目录中，不进入微信小程序，也不进入网页端公开配置。

## 二、系统组成

| 组成部分 | 作用 |
| --- | --- |
| Windows 一键启动程序 | 自动检测 Node.js、启动后端、打开网页端并尝试打开微信开发者工具 |
| 数字网格员网页端 | 工单中心、居民档案、Excel 批量导入、网格员权限和手动派单 |
| 微信小程序居民端 | 地址登记、地址修改、诉求对话、工单进度查看 |
| 数字网格员后端 | 身份认证、居民档案、会话消息、工单落库、分派和权限隔离 |
| HiAgent 智能体 | 意图识别、政策检索、信息补齐、工单草稿和居民回复 |

## 三、Windows 一键启动

### 3.1 准备工作

测试电脑需要满足以下条件：

- Windows 10 或 Windows 11。
- 解压后的项目目录具有写入权限。
- 如需首次自动下载 Node.js，测试电脑需要能够访问互联网。
- 如需查看微信小程序，建议预先安装微信开发者工具。

### 3.2 启动步骤

1. 解压提交压缩包。
2. 进入解压后的 `DigitalGridWorker` 文件夹。
3. 双击 `start-digital-grid-worker.bat`。
4. 如果 Windows 防火墙弹出提示，选择“允许访问”。
5. 脚本会自动启动后端，并打开浏览器。

脚本启动后会自动完成以下操作：

- 检测电脑是否安装 Node.js。
- 如果没有 Node.js，则自动下载便携版到 `.runtime` 目录。
- 检查后端端口是否被占用。
- 启动数字网格员后端。
- 自动打开数字网格员网页端。
- 尝试调用微信开发者工具打开小程序项目。
- 显示管理员和网格员测试账号。

### 3.3 HiAgent 配置选择

脚本首次运行时会询问：

| 选择 | 效果 |
| --- | --- |
| 直接回车或输入 N | 使用本地模拟模式，无需 HiAgent API Key |
| 输入 Y | 填写真实 HiAgent 接口地址、应用 ID、工作流 ID 和 API Key |

评审演示建议直接回车使用本地模拟模式。真实 HiAgent 模式的 API Key 只需要填写一次，后端会保存到本机 `data/runtime/hiagent-config.json`，网页端和小程序会共用该配置。

### 3.4 停止服务

服务启动后，一键启动窗口会保持运行。关闭该窗口或按任意键即可停止后端服务。

## 四、数字网格员网页端

### 4.1 登录

一键启动脚本会自动打开网页端。如果浏览器没有自动打开，可以手动访问启动窗口显示的本地地址，通常为：

```text
http://127.0.0.1:3100
```

测试账号如下：

| 角色 | 账号 | 密码 | 可见范围 |
| --- | --- | --- | --- |
| 系统管理员 | admin | admin123 | 全部工单 |
| 华林社区负责人 | hualin_admin | 123456 | 华林社区工单 |
| 华林网格员01 | hualin01 | 123456 | 派给本人且属于华林网格01的工单 |
| 华林网格员02 | hualin02 | 123456 | 派给本人且属于华林网格02的工单 |
| 观风亭网格员01 | guanfeng01 | 123456 | 派给本人且属于观风亭网格01的工单 |

### 4.2 工单中心

进入“工单中心”后，可以查看当前账号权限范围内的工单。列表包含工单号、居民、诉求类别、事项摘要、责任部门、责任网格员、期限和处理状态。

点击任意工单可以查看详细信息，包括：

- 居民姓名和联系电话。
- 居民登记住址和事发地址。
- 问题描述、发生时间、持续时长和发生频率。
- 是否已经向物业或社区反映。
- 责任部门、责任网格员、优先级和响应时限。

工单列表会自动刷新。小程序端新生成工单后，网页端通常可以在数秒内显示，不需要手动刷新页面。

### 4.3 居民档案与 Excel 批量导入

进入“居民档案”后，可以使用以下入口：

| 入口 | 使用场景 |
| --- | --- |
| 新增登记 | 网格员帮助不熟悉小程序的居民现场代为登记 |
| 批量导入 | 微信群回收标准 Excel 登记表后统一导入 |
| 编辑档案 | 修改居民联系方式、所属社区、网格或地址 |

系统提供标准 Excel 登记表格，字段包括登记类型、姓名、手机号、所属社区、所属网格和现居住地址等。网格员下载表格后发到居民群，居民填写完成并回收，系统会识别新增登记、地址变更和重复档案。

### 4.4 手动派单与权限验证

管理员和社区负责人可以在工单详情中手动改派责任网格员。改派后，原网格员将不再看到该工单，新网格员可以在自己的账号下查看。

权限隔离由后端执行。普通网格员不能通过修改前端页面或接口参数查看其他网格的工单。

## 五、微信小程序居民端

### 5.1 导入项目

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择解压后的 `DigitalGridWorker` 文件夹。
4. 项目配置会自动识别 `miniprogram/` 目录。
5. 点击“编译”。

一键启动脚本会把小程序后端地址自动设置为本机地址，微信开发者工具模拟器通常无需手动修改。

### 5.2 地址登记与修改地址

居民第一次使用时需要先登记地址：

1. 打开小程序首页。
2. 点击“立即登记”。
3. 填写姓名、手机号、所属社区、所属网格和楼栋房号。
4. 勾选个人信息使用说明。
5. 点击“保存并开始使用”。

已登记居民可以修改地址：

1. 在首页点击“修改地址”，或在“我的”页面点击“修改登记”。
2. 系统自动带出原有姓名、社区、网格和地址。
3. 修改地址后点击“保存修改”。

修改地址不会删除历史工单，后端会保留地址变更记录。

### 5.3 居民对话与工单生成

居民在“对话”页面用自然语言描述问题。数字网格员会主动询问缺少的信息，例如：

- 具体事发地址。
- 问题发生时间。
- 持续时长和发生频率。
- 是否已经向物业或社区反映。

居民确认后，系统生成结构化工单。工单会同时保留居民登记住址和事发地址，避免把居民家庭住址误当成问题发生地点。

### 5.4 查看工单

居民可以在小程序“工单”页面查看本人提交的工单，包括工单状态、诉求类别、责任部门、响应时限和处理进度。

### 5.5 手机真机测试

微信开发者工具模拟器可以访问本机地址。手机真机不能访问电脑的 `127.0.0.1`，需要在同一个局域网中测试。

真机测试步骤：

1. 确认手机和电脑连接同一个 Wi-Fi。
2. 查看一键启动窗口显示的局域网地址，例如 `http://192.168.1.100:3100`。
3. 在小程序“我的”页面修改“后端 API 地址”。
4. 点击“保存并重新登录”。
5. 点击“测试连接”，确认连接成功。

局域网地址不是 HiAgent API Key，只是小程序访问电脑后端的地址。

## 六、Excel 批量导入与适老化灵活登记

数字网格员网页端提供两种居民登记方式，覆盖不同使用习惯的人群。

第一，标准 Excel 批量导入。网格员从系统下载标准 Excel 登记表，发到居民微信群，居民填写后回收，再由网格员统一导入系统。系统会自动识别新增档案、地址变更和重复记录。

第二，单个新增登记。对于年龄较大的居民，或者不方便使用微信小程序的居民，网格员可以在网页端直接点击“新增登记”，代为填写姓名、电话、社区、网格和现居住地址。

这两种方式使用同一套居民档案和网格归属规则，登记完成后都可以生成工单并获得正确的网格分派。

## 七、HiAgent 真实接口配置

不使用真实 HiAgent 时，系统使用本地模拟模式。启用真实 HiAgent 时，需要准备以下信息：

| 配置项 | 说明 |
| --- | --- |
| 接口地址 | HiAgent 发布后的 API Endpoint |
| 应用 ID | HiAgent 应用 ID |
| 工作流 ID | HiAgent 工作流 ID |
| API Key | 平台生成的访问密钥 |

一键启动脚本第一次运行时会询问是否配置真实接口。也可以先使用本地模拟模式，之后在数字网格员网页端“系统配置”中填写并保存。保存后，后端和微信小程序会共同使用该配置。

API Key 只保存在后端，不会写入微信小程序，也不会显示在居民端页面。

## 八、常见问题

| 问题 | 原因 | 处理方法 |
| --- | --- | --- |
| 双击启动脚本后窗口一闪而过 | PowerShell 被系统策略拦截 | 右键脚本选择“使用 PowerShell 运行”，或执行 `powershell -ExecutionPolicy Bypass -File .\start-digital-grid-worker.ps1` |
| 网页端打不开 | 后端未启动或端口被占用 | 查看启动窗口和 `server-error.log`，脚本会自动选择其他可用端口 |
| 微信开发者工具没有自动打开 | 未安装微信开发者工具或路径不同 | 手动安装微信开发者工具后，重新运行启动脚本 |
| 模拟器小程序请求失败 | 后端地址与本机端口不一致 | 重新运行一键启动脚本，脚本会自动写入本机后端地址 |
| 手机测试请求超时 | 手机和电脑不在同一网络 | 使用同一 Wi-Fi，并在小程序中填写电脑局域网地址 |
| 小程序显示未登记 | 本地缓存为空或后端地址不正确 | 检查“测试连接”，重新保存地址后再次登记 |
| 真实 HiAgent 请求失败 | 接口地址、应用 ID、工作流 ID 或 API Key 错误 | 在网页端系统配置中核对配置并执行连接测试 |

## 九、数据与安全

系统不会把真实 HiAgent API Key 写入小程序。微信小程序只保存居民登录令牌和后端地址，居民端不显示网格员手机号等内部信息。

提交压缩包不包含以下本机敏感文件：

- `data/runtime/hiagent-config.json`
- `data/runtime/store.json`
- `data/runtime/env.json`
- 本地日志和缓存文件

如果使用真实微信登录，需要在部署电脑上配置微信 AppID 和 AppSecret。该信息同样只由后端使用。

## 十、评审快速演示流程

1. 双击 `start-digital-grid-worker.bat`。
2. 在 HiAgent 配置询问处直接回车，使用本地模拟模式。
3. 浏览器打开数字网格员网页端。
4. 使用 `admin / admin123` 登录。
5. 进入“工单中心”，查看工单字段和分派结果。
6. 打开微信开发者工具，编译小程序。
7. 在小程序中登记或修改地址。
8. 在对话页面提交一条诉求并确认生成工单。
9. 回到网页端，观察工单自动出现并分派给对应网格员。
10. 退出管理员账号，改用 `hualin01 / 123456` 登录，验证只能看到本人工单。
