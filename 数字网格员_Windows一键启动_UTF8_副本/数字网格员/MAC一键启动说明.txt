数字网格员 macOS 一键启动说明

1. 解压整个项目压缩包。
2. 双击“启动数字网格员.command”。
   首次双击若提示“无法打开，因为它来自身份不明的开发者”，请：
   - 右键点击该文件，选择“打开”，再点击“打开”即可；或
   - 在“系统设置 → 隐私与安全性”中点击“仍要打开”。
3. 脚本会自动完成：
   - 检测 Node.js；没有时自动下载 macOS 便携版。
   - 启动数字网格员后端。
   - 自动打开数字网格员网页端。
   - 尝试调用微信开发者工具打开小程序项目。
4. 网页端默认账号：
   - 管理员：admin / admin123
   - 网格员：hualin01 / 123456

没有 HiAgent API Key 也可以运行。脚本询问是否配置真实 HiAgent 时，直接回车即可使用本地模拟模式。

如果要进行手机真机调试，请保证手机与电脑在同一局域网，并在小程序“我的”页面把后端 API 地址改成脚本输出的局域网地址。

关闭脚本窗口或按 Control+C 即可停止后端服务。

若双击后提示没有执行权限，可在终端中运行一次：
   chmod +x "启动数字网格员.command"
