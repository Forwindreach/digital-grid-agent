# 福州市关于进一步推动大众创业万众创新工作的补充意见

- 分类：惠企政策
- 发文机关：福州市人民政府
- 文号：2022年发布
- 发布日期：2022-07-12
- 更新时间：2022-07-12
- 官方原文：http://www.fuzhou.gov.cn/zfxxgkzl/szfbmjxsqxxgk/szfbmxxgk/fzsrmzf/zc/gfxwj/202207/t20220713_4397083.htm

## 政策要点

一、租金减免
对承租市属国有产权双创孵化载体的小微企业，2022年减免6个月租金；鼓励其他市场主体经营的双创孵化载体协商减免入驻小微企业不超过6个月租金，市财政按减免租金总额100%给予最高不超过100万元补助。

二、场地补贴
对符合条件的创业项目租用创业场地给予每年最高3000元补贴，具体以当年度申报指南为准。

三、创业扶持
对符合条件的人员和项目给予一次性创业补贴，扶持优秀创业项目并提供创业工位；创业担保贷款覆盖14类人群，最高额度30万元，同时提高免反担保贷款额度并加大信贷支持。

四、申报渠道
企业可通过福州市惠企政策平台、属地政务服务中心或12345热线咨询申报条件、材料和办理流程。
