# 福州市长者食堂等级评定管理办法

## 政策要点

一、定义
长者食堂是按《福州市长者食堂建设标准》建成，坚持公益性原则，为社区（村）老年人提供就餐、配送餐等普惠性服务的居家社区养老服务场所。

二、申请条件
申请等级评定的长者食堂应运营一年以上，并符合《福州市长者食堂等级评定细则》基本要求；近两年内有重大违法违纪、较大生产安全或服务质量事故等情形不予评定。

三、评定程序
每年集中评定一次。长者食堂对照细则自评后于3月1日前向属地民政部门申请，经资格审核、考核评定、评审公示等程序确定等级；四级及以上由市级民政部门复核。公示期为5个工作日。

四、等级管理
评定等级从低到高为一级至五级，次年可申请晋升；等级评定有效期为三年，自评定年度次年1月起算。各级民政部门每年按不低于10%比例组织抽查复评，不符合标准的降低或取消等级。
