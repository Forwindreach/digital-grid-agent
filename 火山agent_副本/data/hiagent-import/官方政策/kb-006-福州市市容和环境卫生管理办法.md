# 福州市市容和环境卫生管理办法

- 分类：市容环卫
- 发文机关：福州市人民代表大会常务委员会
- 文号：1992年6月27日通过，2012年第五次修正
- 发布日期：1992-06-27
- 更新时间：2012-06-08
- 官方原文：https://rd.fuzhou.gov.cn/fzdfxfg/200804/t20080409_1746734.htm

## 政策要点

一、责任区制度
临街单位、经营户和住宅小区实行市容环境卫生责任区制度，责任区内应保持整洁有序，不得乱倒垃圾、污水，不得乱堆物料、占道经营。

二、市容管理
临街建（构）筑物、店面招牌、广告设施和道路设施应保持整洁规范；不得擅自占道堆放、搭建或影响市容。

三、环境卫生
生活垃圾应按规定投放和清运，公共区域积存垃圾由责任单位或环卫作业单位及时清理；建筑垃圾、装修垃圾不得随意倾倒。

四、投诉处理
居民可通过12345热线、社区网格员或属地城市管理部门反映环境卫生问题，责任部门应依法核查处置并反馈。
