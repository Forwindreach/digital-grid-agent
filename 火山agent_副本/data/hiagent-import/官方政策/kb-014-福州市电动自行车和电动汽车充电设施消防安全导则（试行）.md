# 福州市电动自行车和电动汽车充电设施消防安全导则（试行）

- 分类：消防安全
- 发文机关：福州市住房和城乡建设局、福州市消防救援支队
- 文号：榕建消〔2025〕8号

- 更新时间：2025-02-05

## 政策要点

一、适用范围
适用于福州市行政区域内电动自行车停放充电场所和电动汽车充电设施的消防设计、建设、验收及日常安全管理，配套落实电动自行车安全隐患全链条整治要求。

二、选址与防火
住宅小区配套建设的停放充电场所宜独立设置或与建筑其他部分进行防火分隔，设置单独的防火分区、警示标识，并配置必要的消防设施；公共门厅、疏散走道、楼梯间、安全出口等区域不得违规停放充电。

三、消防设施
室内停放充电场所应按照消防技术标准安装独立式火灾探测报警器和简易自动喷水灭火系统，电气线路和设备应符合安全要求，防止过载充电和电气故障引发火灾。

四、管理责任
物业服务企业、场所管理单位应履行消防安全管理责任，加强日常巡查，及时劝阻违规停放充电行为，发现隐患向消防救援机构或属地网格报告。
