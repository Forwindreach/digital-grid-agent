# 福州市城市养犬管理条例

## 政策要点

一、适用范围
适用于鼓楼区、台江区、仓山区、晋安区、马尾区、长乐区的养犬行为及相关管理活动，不适用于军用犬、警用犬、服务犬等。

二、养犬登记
本市实行养犬登记制度。养犬人应到农业农村部门认定的动物诊疗机构采集身份识别信息、接种狂犬病疫苗，自取得免疫证明之日起10日内通过“e福州”等渠道向所在区城市管理部门申请养犬登记。每户限养一只，禁止饲养列入禁养犬名录的犬只。

三、防疫要求
犬只出生满3个月之日起15日内或免疫有效期届满前应接种狂犬病疫苗；犬只伤人的，养犬人应立即送医诊治，并在24小时内将伤人犬只送检狂犬病抗体。

四、行为规范
携犬出户应佩戴犬牌并使用不超过1.5米的束犬绳（链）牵领，主动避让他人，即时清除犬粪，乘坐电梯或上下楼梯应采取安全措施；禁止使用伸缩犬绳、携犬乘坐除出租汽车以外的公共交通工具、遗弃犬只、占用公共区域养犬。党政机关、学校、医院、文化体育场馆等场所禁止携犬进入。

五、法律责任
未办理养犬登记的个人处500元以上1000元以下罚款；饲养禁养犬每只罚2000元；携犬出户未即时清除犬粪拒不改正的处50元以上200元以下罚款；犬吠扰民拒不改正的由公安机关依法处罚。
