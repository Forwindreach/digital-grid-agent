# 福建省城乡生活垃圾管理条例

- 分类：市容环卫

- 发布日期：2019-07-25

## 政策要点

一、适用范围
适用于福建省行政区域内生活垃圾的源头减量、分类投放、分类收集、分类运输、分类处置及监督管理活动。

二、源头减量
县级以上人民政府应建立生活垃圾源头减量机制，引导单位和个人减少垃圾产生，推进可回收物回收利用。

三、分类投放
单位和个人应当履行生活垃圾分类投放义务，按照地方分类标准投放生活垃圾；住宅小区物业服务企业、村（居）民委员会等负责宣传和监督管理。

四、收运处置
分类收集、运输、处置企业应按规定作业，禁止混合运输已分类的生活垃圾；违反规定的由主管部门依法查处。
