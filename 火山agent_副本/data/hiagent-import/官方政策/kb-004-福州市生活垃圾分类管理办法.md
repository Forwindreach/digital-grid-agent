# 福州市生活垃圾分类管理办法

- 发文机关：福州市人民政府

- 发布日期：2019-03-29
- 更新时间：2019-05-01

## 政策要点

一、分类标准
生活垃圾分为可回收物、有害垃圾、易腐垃圾、大件垃圾和其他垃圾。可回收物包括纸类、塑料、金属、玻璃等；有害垃圾包括废弃电池、荧光灯管、药品等；易腐垃圾包括餐厨垃圾、厨余垃圾和废弃果蔬等。

二、投放要求
单位和个人应按规定的地点、方式分类投放，不得随意抛弃、倾倒、堆放。大件垃圾应单独临时堆放并预约收运企业上门收集；餐厨垃圾应沥干水分后投放至专用收集容器。

三、管理责任人
实行物业管理的区域由物业服务企业为管理责任人；未实行物业管理的区域按单位自管、村（居）民委员会、经营单位、运营服务单位、维护单位或建设单位等确定。责任人应设置收集容器、公示投放要求、指导监督分类投放并建立台账。

四、法律责任
未按规定分类投放、拒不改正的，对个人处50元以上200元以下罚款，对单位处5000元以上5万元以下罚款；管理责任人未履行义务、逾期未改正的，处5000元以上1万元以下罚款。
