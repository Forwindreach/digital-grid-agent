# 现场演示脚本

演示目标：在 5 分钟内呈现「数字网格员」从诉求接入到人工归档的完整闭环，重点展示多 Agent 协作、RAG 引用溯源与人机协同。

## 演示流程

1. 打开 `index.html`，停留在「诉求受理台」。
2. 点击居民档案按钮，按姓名、手机号或楼栋房号检索居民并切换，再演示一次“新增登记”，展示千人网格下的快速建档。
3. 打开“批量导入”，下载居民信息登记表模板；选择一份含“新增登记”和“地址变更”的 .xlsx 或 .csv，预览后确认导入，展示系统自动识别新增与搬家地址。
4. 逐一点击示例场景，提交 2-3 条不同类别诉求。
5. 右侧「Agent 处理链路」实时展示节点执行状态与耗时。
6. 处理完成后展示工单、责任部门、回复与引用来源。
7. 网格员点击「确认归档」，切换「工单中心」与「数据看板」查看闭环记录与指标。

## 场景一：环境卫生

输入：

```text
楼下垃圾堆了好几天没人清，天气热味道很大，地址在华林花园3号楼门口，麻烦尽快处理。
```

预期：

- 分类：环境卫生，置信度高
- 责任部门：鼓楼区环卫中心
- 响应时限：24 小时
- 回复包含工单号与处理时限

## 场景二：噪音扰民

输入：

```text
五四路193号旁边的工地半夜还在施工，声音很大，吵得睡不着，请问这种情况怎么投诉？
```

预期：

- 分类：噪音扰民
- 责任部门：鼓楼区城管中队
- 引用《中华人民共和国噪声污染防治法》中夜间施工条款
- 回复包含投诉渠道与依据

## 场景三：违建隐患

输入：

```text
湖东路123号2号楼顶楼有人私自加盖，担心有安全隐患，想请网格员上门看看。
```

预期：

- 分类：违法建设
- 优先级：高，进入人工复核队列
- 工单转鼓楼区城管中队

## 场景四：政策咨询

输入：

```text
我想问下福州市对小微企业有房租减免政策吗？申请需要什么材料？
```

预期：

- 分类：政策咨询
- RAG 命中《福州市支持小微企业发展的若干措施》
- 回答附引用来源，并提示办理渠道

## 场景五：养老服务

输入：

```text
家里老人想申请社区助餐服务，需要什么条件，怎么办理？
```

预期：

- 分类：养老服务
- RAG 命中《鼓楼区社区居家养老服务实施方案》
- 回复申请条件与办理流程
- 工单转温泉街道社区服务中心

## 讲解要点

- 强调「Agent 自动执行 → 人类最终确认」：Agent 生成工单与回复，但归档必须由网格员点击确认。
- 强调 RAG 溯源：政策回答不是模型记忆，而是检索知识库后的引用回答。
- 强调多 Agent 架构：语音识别、意图识别、知识检索、工单生成、居民回复为独立节点，便于单独升级与评测。
