# 合体指南：本地演示接入 HiAgent 真实接口

合体目标：本地演示页面负责界面展示，HiAgent 负责真实 Agent 执行。居民在演示页面提交诉求后，页面调用 HiAgent 发布后的接口，把真实回答展示在同一个界面里。

当前项目已经完成「前端 + 后端」合并：

- 前端：`index.html`、`app.js`、`styles.css` 等演示界面
- 后端：`server.js`（Node 静态服务 + HiAgent 代理）

后端代理解决两件事：浏览器跨域问题，以及不把 API Key 暴露在前端代码里。

## 第 0 步：启动合并后的项目

```bash
cd /Users/vincent/Documents/ChatGPT/火山agent
node server.js
```

浏览器打开 `http://127.0.0.1:3000`。

## 第 1 步：在 HiAgent 发布应用

1. 打开「数字网格员」应用，进入顶部「发布」页签。
2. 点击「发布配置」，填写版本号和版本说明，点击「确定」。
3. 确认应用状态变为「已发布」。

## 第 2 步：获取接口地址与密钥

1. 在「发布配置」或「集成」模块中找到应用调用信息。
2. 复制：
   - 接口地址（API Endpoint，形如 `http://14.103.118.162:32300/.../chat`）
   - 应用 ID（已有：`personal-d9fih1mmreq4ugfv7o5g`）
   - 工作流 ID（已有：`d9mr3rhb9rsa732g1ajg`）
   - API Key（平台生成的访问密钥）

## 第 3 步：在本地演示中填写配置

1. 在 `http://127.0.0.1:3000` 打开页面，进入「系统配置」。
2. 「运行模式」选择「HiAgent 真实接口」。
3. 填写：
   - 接口地址：第 2 步复制的 API Endpoint
   - 应用 ID、工作流 ID、API Key
4. 点击「保存配置」。

## 第 4 步：测试

1. 点击「连接测试」，验证接口可达。
2. 回到「诉求受理台」，提交一条政策咨询或投诉。
3. 右侧 Agent 链路会显示「HiAgent 实时处理」，等待真实回复返回。

## 常见问题

### 浏览器提示跨域（CORS）

使用 `node server.js` 启动后无需处理 CORS，请求由本地代理转发。

### 接口返回格式不同

`hiagent-client.js` 目前按常见格式解析：

```text
reply / answer / output / text / message
```

如果平台返回字段不同，打开 [hiagent-client.js](/Users/vincent/Documents/ChatGPT/火山agent/hiagent-client.js) 的 `normalize()` 函数，把实际字段名加进候选列表即可。

### 调用失败

优先检查：

- 应用是否已发布
- 接口地址是否以 `http://` 开头
- API Key 是否正确
- 页面右下角提示的具体错误信息

如果按以上步骤仍无法接通，把报错信息发给我，我来帮你排查并接入。
