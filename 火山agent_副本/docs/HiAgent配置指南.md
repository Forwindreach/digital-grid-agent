> 个人空间应用 ID：`personal-d9fih1mmreq4ugfv7o5g`
> 账号信息请通过平台安全渠道配置，不要写入代码或文档。

## 1. 登录与创建应用

1. 打开平台地址，进入个人空间。
2. 在「应用」列表中选择或新建「数字网格员」应用。
3. 确认应用 ID 为 `personal-d9fih1mmreq4ugfv7o5g`，或在配置中替换为实际应用 ID。
4. 选择基础模型：建议 `doubao-pro-32k` 或平台提供的等价模型。

## 2. 创建知识库并导入官方政策

1. 进入「知识库」模块，新建知识库「福州社区治理政策库」。
2. 选择向量检索方案，向量维度与平台默认配置一致。
3. 导入方式二选一：
   - 直接上传 `data/hiagent-import/官方政策/` 下的 21 篇 Markdown 文件（推荐，保留标题、文号、官方原文链接）。
   - 或导入 `data/policy_kb.json`：
   - 字段映射：`title` → 标题，`content` → 正文，`category` → 分类标签，`keywords` → 关键词，`source` → 来源，`updateDate` → 更新时间，`url` → 官方原文链接。
   - 如平台不支持 JSON 直接导入，可将 `content` 字段导出为 Markdown/CSV 后导入。
4. 启动向量化并确认文档数量（建议 21 篇）与分块状态正常。

## 3. 编排多 Agent 工作流

在「工作流」或「多 Agent 编排」中创建以下节点，并按顺序连接：

| 节点 | 职责 | 输入 | 输出 |
| --- | --- | --- | --- |
| 语音识别 | 语音转文字 | 语音文件 | transcript, confidence |
| 意图识别 | 诉求分类 | transcript/text | category, address, priority |
| 上下文补全 | 关联居民档案 | resident_id | history, tags, risk |
| 知识检索 | RAG 检索 | question | hits, citations |
| 工单生成 | 部门匹配与派单 | category, address | ticket_no, department, sla |
| 居民回复 | 渠道化回复 | intent, citations, ticket | reply_text |
| 人工确认 | 人工审核与归档 | 全部结果 | status: archived / review |

建议为每个节点配置结构化输出，避免下游依赖不稳定文本。

## 4. 节点提示词要点

### 意图识别

```text
你是社区治理诉求分类助手。从居民消息中提取：
- category：环境卫生 / 噪音扰民 / 违法建设 / 物业服务 / 养老服务 / 政策咨询 / 其他
- address：具体地址
- urgency：高 / 中 / 低
- confidence：0-1 的置信度
只输出 JSON。
```

### 知识检索回答

```text
你是政策咨询助手。必须基于给定知识块回答，回答末尾标注引用来源。
如果知识块不足以回答，必须输出「需要人工复核」，禁止编造政策。
```

### 居民回复

```text
你是社区网格员助手。回复需礼貌、简洁、明确：
- 已受理事项：告知工单号、责任部门、预计响应时限
- 政策咨询事项：给出要点并附引用来源
不要承诺 Agent 无法保证的处理结果。
```

## 5. 人工确认与归档

1. 配置「人工确认」为工作流末端节点。
2. 设置自动通过条件：类别为政策咨询、置信度 ≥ 85% 且无敏感标签。
3. 强制复核条件：违法建设、紧急救助、低置信度、重复投诉、敏感投诉。
4. 归档操作仅在网格员确认后写入闭环记录。

## 6. 接入演示系统

1. 在 HiAgent 平台发布应用 API。
2. 在演示系统「系统配置」中填写：
   - 平台地址
   - 应用 ID
   - API Key
   - 模型
3. 将 `app.js` 中的模拟流水线替换为对 HiAgent 的请求：
   - 用户提交诉求 → 调用工作流 API
   - 流式返回各节点输出与最终回复
   - 展示在「诉求受理台」与「Agent 处理链路」面板

> API Key 属于敏感信息，应通过环境变量或平台密钥服务注入，不要提交到 Git。

## 7. 评测与验收

建立测试集，覆盖：

- 5 类以上诉求分类正确率
- 政策咨询答案与引用来源一致性
- 地址与责任部门匹配准确率
- 端到端处理耗时
- 人工复核召回情况

建议按 100 条真实脱敏样例进行回归评测，政策问答准确率目标 ≥ 90%。
