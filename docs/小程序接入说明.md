# 数字网格员微信小程序接入说明

## 架构

```text
居民微信小程序
  -> 数字网格员后端 API
  -> 后端打包居民档案、地址、历史对话
  -> HiAgent 数字网格员应用
  -> 后端保存回复并落库工单
  -> 小程序展示回复与工单进度
```

小程序不直接携带 HiAgent API Key，也不直接调用 HiAgent。所有身份校验、地址登记、会话消息、工单生成和推送都由后端统一完成。

## 本地启动

```bash
npm start
```

浏览器访问 `http://127.0.0.1:3100` 可使用数字网格员 Web 工作台。

微信开发者工具：

1. 导入本项目根目录。
2. 项目配置已设置 `miniprogramRoot: "miniprogram/"`。
3. 本地调试已关闭合法域名校验，默认后端地址为 `http://127.0.0.1:3100`。
4. 打开首页后会自动以开发模式登录；未配置微信 AppSecret 时后端使用本地 `mockOpenid`，方便联调。

如需连接其他后端，在「我的」页面修改 API 地址并保存。

## 后端 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/wechat/login` | 微信 code 登录，返回 token 与居民档案 |
| GET | `/api/me` | 获取当前居民档案 |
| POST | `/api/residents/register` | 地址与身份登记 |
| GET | `/api/conversation` | 获取当前会话和全部消息 |
| POST | `/api/messages` | 提交居民消息，返回处理中状态 |
| GET | `/api/work-orders` | 当前居民工单列表 |
| GET | `/api/work-orders/:id` | 工单详情 |
| POST | `/api/work-orders/:id/confirm` | 居民确认工单草稿 |
| GET | `/api/runtime/config` | 当前运行模式，不暴露密钥 |
| POST | `/api/hiagent` | 保留原演示页 HiAgent 代理 |
| GET | `/api/health` | 健康检查 |

消息提交采用异步处理：`POST /api/messages` 立即返回 `status: "processing"`，小程序轮询 `/api/conversation`，直到出现对应的 `reply-{requestId}` 回复。这样 HiAgent 工作流即使耗时较长，也不会阻塞居民端。

投诉类消息会先与居民交互确认：数字网格员先整理问题、地址和补充信息，请居民回复“确认提交”后才会生成正式工单；政策咨询则先确认居民想了解的具体事项，避免一上来就给出固定模板回复。

## 接入真实 HiAgent

后端未配置 HiAgent 时使用本地模拟回复，便于离线联调。接入真实平台通过环境变量：

```bash
export HIAGENT_ENDPOINT="https://your-hiagent-endpoint"
export HIAGENT_APP_ID="your-app-id"
export HIAGENT_WORKFLOW_ID="your-workflow-id"
export HIAGENT_API_KEY="your-api-key"
node server.js
```

也可以写入 `data/runtime/hiagent-config.json`：

```json
{
  "endpoint": "https://your-hiagent-endpoint",
  "appId": "your-app-id",
  "workflowId": "your-workflow-id",
  "apiKey": "your-api-key"
}
```

该文件被静态服务禁止访问，且已加入 `.gitignore`。正式环境仍建议使用环境变量或密钥服务。

微信登录接入真实 openid：

```bash
export WECHAT_APP_ID="wx..."
export WECHAT_APP_SECRET="your-app-secret"
node server.js
```

未配置时后端接受 `mockOpenid`，仅用于本地开发。

## 数据与安全

- 居民、会话、消息、工单保存在 `data/runtime/store.json`，属于本地演示存储；上线前应替换为正式数据库。
- `data/runtime/` 不会通过静态服务暴露。
- HiAgent API Key 和微信 AppSecret 只出现在后端环境变量中。
- 工单仍遵循「Agent 起草 -> 居民确认 -> 网格员处置 -> 人工归档」的人机协同原则。

## 上线前还需要

1. 后端部署到公网 HTTPS，并在微信公众平台配置 request 合法域名。
2. 小程序申请政务服务或社区服务相关类目，完成隐私保护指引。
3. 将 `data/runtime/store.json` 替换为正式数据库，并增加备份、权限与审计。
4. 增加微信订阅消息，工单状态变化时主动推送居民。
5. 配置 HiAgent 发布版本和工作流版本，避免小程序与网格员工作台使用不同 Agent 配置。
