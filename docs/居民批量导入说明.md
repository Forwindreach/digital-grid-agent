# 居民档案批量导入说明

## 目标场景

社区网格员把 Excel 登记表发到居民群，居民填写姓名、手机号、居住地址后回收表格，系统一键导入并自动区分“新增登记”与“地址变更”。

## 模板文件

模板位于 `data/templates/居民信息登记表.xlsx`，包含两个工作表：

- `登记表`：居民实际填写的表格，含下拉选项和 100 行空白数据区。
- `填写示例`：字段说明和新增、地址变更两条示例。

## 操作步骤

1. 在页面“居民档案登记”中点击“批量导入”。
2. 点击“下载居民信息登记表模板”，把文件发到居民群。
3. 居民按行填写：登记类型、姓名、手机号、所属社区、所属网格、现居住地址（楼栋房号）等。
4. 回收表格后，回到页面“批量导入”，选择 `.xlsx` 或 `.csv` 文件。
5. 页面显示导入预览，自动标记每条记录为“新增 / 更新 / 跳过”。
6. 核对无误后点击“确认导入”，系统按手机号或姓名匹配居民档案。

## 自动识别规则

- 手机号能匹配到现有居民：更新该居民档案；地址不同的，视为搬家地址变更。
- 手机号匹配不到、姓名也匹配不到的：新建居民档案。
- 缺少姓名或现居住地址的行：跳过并在预览中标红提示。
- 档案已存在且信息无变化：跳过，不重复建档。

## 隐私提示

登记表包含居民姓名、手机号、住址等个人信息，仅供社区网格治理使用。群内发放和回收时建议通过企业微信群或社区小程序等受控渠道，回收后及时导入系统并妥善清理群内表格。
