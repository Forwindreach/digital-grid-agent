# 一键部署说明

## macOS / Linux

```bash
chmod +x scripts/deploy/deploy-macos.sh
./scripts/deploy/deploy-macos.sh
```

首次运行会检查 Node.js、创建 HiAgent 配置，并可选配置微信 AppID/AppSecret。

Linux 服务器也可以使用专用脚本：

```bash
chmod +x scripts/deploy/deploy-linux.sh
sudo ./scripts/deploy/deploy-linux.sh
```

脚本会自动检测 `apt-get`、`dnf` 或 `yum` 安装 Node.js，并读取服务器局域网 IP。

## Windows

以普通用户或管理员身份打开 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\deploy\deploy-windows.ps1
```

以管理员身份运行时，脚本会自动添加 Windows 防火墙放行规则。

## 说明

- 项目默认端口为 `3100`，也可以通过 `PORT` 环境变量修改。
- HiAgent 配置保存在 `data/runtime/hiagent-config.json`。
- 微信配置保存在 `data/runtime/env.json`，仅用于本地环境变量注入，不会提交到 Git。
- 居民和工单数据保存在 `data/runtime/store.json`。
- 脚本默认前台运行，按 `Ctrl+C` 停止。
