数字网格员 Windows 一键启动说明

1. 解压整个项目压缩包。
2. 双击 scripts\launch\start-windows.bat。
3. 脚本会自动完成：
   - 检测 Node.js；没有时自动下载便携版。
   - 启动数字网格员后端。
   - 自动打开数字网格员网页端。
   - 尝试调用微信开发者工具打开小程序项目。
4. 网页端默认账号：
   - 管理员：admin / admin123
   - 网格员：hualin01 / 123456

没有 HiAgent API Key 也可以运行。脚本询问是否配置真实 HiAgent 时，直接回车即可使用本地模拟模式。

如果要进行手机真机调试，请保证手机与电脑连接同一个手机热点，并在小程序“我的”页面把后端 API 地址改成脚本输出的局域网地址。
电脑同时连接网线和手机热点时，Windows 脚本会优先显示 Wi-Fi/手机热点地址，并注明所选网卡；无需拔掉网线。

如果 Windows 防火墙弹出提示，请选择“允许访问”。
