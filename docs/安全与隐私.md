# 安全与隐私说明

本仓库公开的是比赛演示与学习版本，默认使用模拟数据，不应录入真实居民个人信息。

## 配置边界

- HiAgent API Key、微信 AppSecret 等凭证仅保存在本地 `data/runtime/` 或环境变量中。
- `data/runtime/`、`.env*` 与微信开发者工具私人配置已经加入 `.gitignore`。
- `project.config.json` 使用微信开发者工具的访客 AppID；联调自己的小程序时请在本地替换。
- `resources/hiagent-exports/` 是不含访问凭证的比赛配置导出包。

## 数据边界

- 网页与小程序中的姓名、手机号、地址和工单均为演示数据。
- 公开知识库来自政府公开渠道，仓库保留标题和来源信息；用于真实服务前仍需核对政策时效性。
- 真实部署应增加数据库访问控制、传输加密、审计日志、数据脱敏、备份和权限分级。

如果发现敏感信息或安全问题，请不要在公开 Issue 中粘贴凭证或个人数据。
